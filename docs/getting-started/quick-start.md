# Quick start

This path is for an approved internal user running a query from Python under
their own Microsoft Entra identity.

## 1. Confirm access

Ask the API owner to grant your user account **Run Queries and Mutations** on the
Fabric GraphQL API item. The permission name is generated by Fabric; this API is
operated as read-only and the published schema should expose query operations
only.

Depending on how the API connects to its data source, you might also need read
permission on the underlying Fabric data item. See
[access and permissions](access.md).

## 2. Download the example

Clone this repository or download the `examples/python` directory. Then open a
terminal in that directory.

## 3. Create a Python environment

=== "Windows PowerShell"

    ```powershell
    py -m venv .venv
    .\.venv\Scripts\Activate.ps1
    python -m pip install -r requirements.txt
    ```

=== "macOS or Linux"

    ```bash
    python3 -m venv .venv
    source .venv/bin/activate
    python -m pip install -r requirements.txt
    ```

## 4. Run the query

```bash
python query_currency.py
```

The terminal displays a Microsoft device-login URL and a short code. Open the
URL, enter the code, and sign in with the account that was granted API access.
The script then prints the GraphQL JSON response.

No database connection string is required. The client calls the GraphQL HTTPS
endpoint and the Azure Identity library obtains a short-lived access token.

## 5. Use another query

Replace the GraphQL document and `variables` dictionary in the example, or use
the reusable client described in the [Python guide](../clients/python.md). Copy
operations from the [query catalogue](../queries/reference-data.md).

## Expected response

```json
{
  "data": {
    "currencies": {
      "items": [
        {
          "Id": 1,
          "Code": "USD"
        }
      ],
      "hasNextPage": false,
      "endCursor": null
    }
  }
}
```

The numeric ID is illustrative; use the value returned by the API.
