What is the GraphQL API?

The Humanitarian Action GraphQL API provides read-only access to humanitarian planning and response data.

The API includes reference data, plans, projects, emergencies, sectors, coordination entities, requirements and organizations.

With GraphQL, you specify the fields you need. You can also request related data in the same query. The JSON response follows the structure of your query.

GraphQL and REST

The main difference is how clients identify the data they want to retrieve.

REST

Multiple resource URLs

REST commonly provides separate URLs for resources such as plans, projects and emergencies. The server defines the standard response returned by each URL.

GraphQL

One endpoint, flexible queries

A GraphQL request identifies the data, fields, filters, related records and pagination instructions required by the client.

How to try a query

Follow these steps after you have registered and received permission to use the API.

  1. Sign in to the developer portal and complete your registration.
  2. Wait for an administrator to grant the required API permission. You do not need to subscribe to a product.
  3. Open the Sample Queries page.
  4. Select an example and copy its GraphQL query and variables.
  5. Open the APIs page and select api-hpc-prod - v1.
  6. Select Try this operation to open the test console.
  7. Paste the GraphQL query into the query field and its JSON variables into the variables field.
  8. Change the variable values if needed, send the request and review the returned JSON response.
!

This portal is for testing only

Use the playground for small, occasional requests. It is not the supported connection route for:

  • Production applications
  • Scheduled jobs or ETLs
  • Large data downloads
  • High-volume requests
  • Long-running or deeply nested queries
  • Multiple large concurrent requests

Start with no more than 100 records and use GraphQL pagination when additional records are required.

Need direct API access?

For regular use from Python, C#, Node.js, Postman, Excel, an ETL or another application, request direct access to the Microsoft Fabric GraphQL API.
